# Pingo Chat

پیام‌رسان تحت وب با **Next.js 16 (App Router)**، Socket.IO و SQLite داخلی Node.js — قابل نصب به‌صورت **PWA**.

## امکانات
- رابط شیشه‌ای (Glassmorphism) با پس‌زمینه‌ی زنده، حالت شب/روز، ۶ تم رنگی، انتخاب فونت و اندازه‌ی متن
- نوار پایین: گفتگوها، مخاطبین، تنظیمات، پروفایل
- پیوی، **پیام‌های ذخیره‌شده** (همیشه بالای لیست)، **گروه تا ۱٬۰۰۰ عضو**
- گروه‌ها مثل تلگرام: لینک دعوت خصوصی `pingochat.ir/+کد` (کپی، اشتراک، QR، باطل‌کردن)، مدیران، انتقال مالکیت،
  دسترسی اعضا (ارسال پیام / ارسال رسانه)، عکس و توضیحات گروه، حذف و افزودن عضو، ترک و حذف گروه
- حذف پیام (برای همه)، ویرایش پیام با برچسب «ویرایش‌شده»، فوروارد هر نوع پیام به پیوی، گروه و پیام‌های ذخیره‌شده
- ارسال ویدیو و **پیام ویدیویی دایره‌ای** (ضبط با دوربین، حداکثر ۶۰ ثانیه) در پیوی و گروه
- تیک‌های رسمی آبی، مشکی و سفید؛ نشان **OWNER** فقط برای مالک
- پنل مدیریت: تعیین مدیر پنل از داخل برنامه، تیک‌ها، تغییر رمز، مسدودسازی، آمار، و **اطلاعیه/تبلیغ سنجاق‌شده** (متن + عکس + مدت زمان) برای همه‌ی کاربران
- ذخیره‌ی **هر نوع پیام** (متن، عکس، فایل، ویس) در پیام‌های ذخیره‌شده با برچسب «بازارسال از …»
- تنظیمات گروه: افزودن عضو با جستجو، افزودن مدیر از بین اعضا، برداشتن مدیریت
- رابط شیشه‌ای مات (Blur) و انیمیشن برای باز و بسته شدن پنجره‌ها، منوها، صفحه‌ها و دکمه‌ها
- **پیام صوتی** با شکل موج، پخش پشت‌سرهم و جابه‌جایی روی موج
- وضعیت‌های زنده: «در حال نوشتن»، «در حال ارسال عکس»، «در حال ارسال فایل»، «در حال ضبط صدا»
- پاسخ (کشیدن به چپ در موبایل)، ری‌اکشن، عکس و فایل تا ۲۰ مگابایت، @یوزرنیم و لینک‌های داخلی قابل کلیک
- لینک پروفایل `pingochat.ir/username` و کد QR
- مخاطبین، مسدودسازی کاربران، مخفی کردن آخرین بازدید، دستگاه‌های فعال، تغییر رمز
- اعلان مرورگر و صدای پیام، دانلود خودکار عکس، صرفه‌جویی انرژی (حذف انیمیشن و جلوه‌ی شیشه‌ای)
- پنل مدیریت (آمار، کاربران، ورودها، تیک آبی، مسدودسازی) — بدون دسترسی به متن پیام‌های خصوصی

## ساختار
```
server.js              سرور اختصاصی Next.js: API (Express) + Socket.IO + دیتابیس
app/layout.js          قالب اصلی، فونت وزیرمتن (self-hosted)، metadata و viewport
app/page.js            صفحه‌ی اصلی
app/[slug]/page.js     لینک‌های عمومی: /username و /+کد_دعوت
app/manifest.js        Web App Manifest (‏/manifest.webmanifest)
app/globals.css        طراحی شیشه‌ای
components/            Shell.jsx (ساختار رابط) و PingoApp.jsx (کامپوننت کلاینت)
lib/pingo-client.js    منطق سمت کاربر (فقط در مرورگر)
public/sw.js           Service Worker
public/icons/          آیکون‌های PWA
setup.sh               نصب خودکار روی سرور Ubuntu
```

چرا سرور اختصاصی؟ چت بلادرنگ به اتصال WebSocket همیشه‌باز نیاز دارد که Route Handlerهای Next.js آن را پشتیبانی نمی‌کنند؛
برای همین از الگوی رسمی «Custom Server» استفاده شده و صفحه‌ها، API و Socket.IO در یک پردازش اجرا می‌شوند.

## اجرا
نیازمند Node.js نسخه‌ی ۲۲.۱۳ یا جدیدتر.
```bash
npm install
npm run dev            # توسعه
npm run build          # ساخت نسخه‌ی نهایی
npm start              # اجرای نسخه‌ی نهایی
```

## متغیرهای محیطی
- `JWT_SECRET` رشته‌ی تصادفی طولانی (ضروری)
- `DB_PATH` مسیر دیتابیس، مثلاً `/opt/arian-data/messenger.db` (فایل‌ها در پوشه‌ی `uploads` کنار آن)
- `ADMIN_USERNAME` یوزرنیم مالک (اولین نام) و مدیرهای ثابت، با کاما؛ مدیرهای دیگر از داخل پنل تعیین می‌شوند
- `PORT` پیش‌فرض 3000

## PWA و راهبرد کش (public/sw.js)
| منبع | راهبرد | دلیل |
|---|---|---|
| صفحه‌ها (HTML) | اول شبکه (۴ ثانیه)، سپس کش | همیشه آخرین نسخه، ولی آفلاین هم باز می‌شود |
| `/_next/static/*` | اول کش | فایل‌های هش‌دار تغییرناپذیرند |
| لوگو، آیکون‌ها، manifest | کش + به‌روزرسانی در پس‌زمینه | سرعت بالا، به‌روز ماندن |
| عکس پروفایل و عکس پیام‌ها | اول کش، حداکثر ۳۰۰ مورد | شناسه‌ها یکتا و تغییرناپذیرند؛ با خروج از حساب پاک می‌شوند |
| API، Socket.IO، ویس، دانلود فایل | فقط شبکه | داده‌ی زنده و خصوصی کش نمی‌شود |

نسخه‌ی جدید خودکار شناسایی می‌شود و دکمه‌ی «به‌روزرسانی» به کاربر نمایش داده می‌شود.
بعد از هر تغییر در `public/sw.js` مقدار `VERSION` را بالا ببرید.
