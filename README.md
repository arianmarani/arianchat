# Arian Chat

پیام‌رسان تحت وب با Node.js، Express، Socket.IO و SQLite داخلی Node.js.

## امکانات
- ثبت‌نام با نام پروفایل، یوزرنیم یکتا و ایمیل؛ ورود با ایمیل یا یوزرنیم
- عکس پروفایل، بیوگرافی (تا ۷۰ کاراکتر) و ویرایش نام، یوزرنیم و ایمیل از منوی ☰ ← «ویرایش پروفایل»
- مشاهده‌ی پروفایل طرف مقابل با زدن روی نام او در بالای چت
- پاسخ (ریپلای) به پیام‌ها؛ با کلیک روی نقل‌قول به پیام اصلی می‌رود
- ارسال عکس و فایل تا ۲۰ مگابایت (دکمه‌ی 📎، کشیدن و رها کردن، یا Ctrl+V برای عکس)
- @یوزرنیم داخل پیام‌ها و بیوگرافی قابل کلیک است و پیوی همان کاربر را باز می‌کند
- تنظیمات ظاهر: اندازه و فونت پیام‌ها، ۶ تم رنگی، حالت روشن/تیره/خودکار (منوی ☰ ← «تنظیمات ظاهر و فونت»)
- جستجوی کاربر با یوزرنیم، چت بلادرنگ، وضعیت آنلاین، «در حال نوشتن…»، تیک خوانده‌شدن
- ری‌اکشن روی پیام‌ها: دابل‌کلیک = 👍، کلیک راست یا دکمه‌ی ☺ = انتخاب، در موبایل لمس طولانی
- تم بنفش روشن و سفید، حالت تیره‌ی خودکار، واکنش‌گرا برای موبایل

## اجرا
نیازمند Node.js نسخه‌ی ۲۲.۱۳ یا جدیدتر.
```bash
npm install
npm start
```
سپس `http://localhost:3000` را باز کنید.

## متغیرهای محیطی (برای سرور)
- `JWT_SECRET`: یک رشته‌ی تصادفی طولانی (ضروری)
- `DB_PATH`: مسیر فایل دیتابیس روی دیسک ماندگار، مثلاً `/data/messenger.db`. فایل‌های ارسالی در پوشه‌ی `uploads` کنار همین فایل ذخیره می‌شوند.
- `PORT`: معمولاً سرویس میزبان خودش تنظیم می‌کند

اگر دیتابیس نسخه‌ی قبلی را دارید، ستون‌های جدید خودکار اضافه می‌شوند و حساب‌ها و پیام‌ها حفظ می‌شوند.
